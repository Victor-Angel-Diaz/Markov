# Herramientas Markov — uso en tu PC

## Descargar desde GitHub

1. Abre https://github.com/Victor-Angel-Diaz/Markov.
2. Pulsa el botón verde **Code** y elige **Download ZIP**.
3. En Descargas, pulsa con el botón derecho sobre `Markov-main.zip` y elige **Extraer todo**.
4. Abre la carpeta extraída `Markov-main`.
5. Haz doble clic en `index.html`. Si Windows pregunta con qué abrirlo, elige Edge, Chrome o Firefox.
6. Selecciona la herramienta que quieras usar.

No abras los HTML dentro del ZIP: extrae primero todos los archivos. Conserva la carpeta `Otros` junto al índice para que la guía siga funcionando. No necesitas instalar MATLAB, Python ni Node para utilizar las herramientas.

## Archivos locales

Estos HTML ejecutan sus cálculos en el navegador. Los gráficos, las fuentes y el diagrama cargan bibliotecas de internet; **esta entrega necesita conexión para mostrar todos sus elementos**. No se presenta como un paquete completamente offline. Si una biblioteca no carga, conecta internet y recarga. El protocolo incluye una alternativa textual.

Algunas operaciones de portapapeles pueden depender de permisos del navegador o del uso de HTTPS. Para resultados, usa **Descargar resultados y configuración**; también aparecerá un resumen seleccionable y un enlace **Descargar archivo exportado**. Si el navegador bloquea una descarga, selecciona el resumen, cópialo y pégalo en el Bloc de notas.

Los datos ingresados se procesan en el navegador. No publiques datos personales en el repositorio. Para actualizar la copia local, descarga y extrae de nuevo el ZIP; conserva tus resultados en una carpeta aparte.
